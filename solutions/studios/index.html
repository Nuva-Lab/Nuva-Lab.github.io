The studio problem

Generation volume is easy. Production continuity is hard.

Public video APIs are useful for exploration, but studio production exposes a different problem: the same cast, art direction, camera language, aspect ratios, and delivery rules must survive across many shots and many operators.

When references leave the studio on every request, queues change without notice, or model behavior shifts during a deadline, the nominal price per generation stops describing the real cost. Rejected takes, continuity repair, manual handoffs, and idle artists become the larger production tax.

Qualification

Prove the production case before buying hardware

We start with a bounded set of representative scenes, difficult references, target formats, current provider outputs, and the studio's own acceptance rubric. Candidate models and runtime configurations are compared on quality first, then complete-output latency, throughput, failure rate, and total operating cost.

A deployment recommendation includes the target model profile, GPU topology, storage and networking assumptions, serving interface, operator workflow, capacity model, and rollback path. We do not turn a public benchmark into a studio SLA.

Good qualification inputsMonthly accepted minutes, attempts per accepted shot, target resolutions and durations, recurring assets, current provider spend, deadline peaks, review criteria, deployment region, and privacy requirements.

Model and license boundary

Portable infrastructure, authorized model use

Nuva Lab can evaluate MiniMax H3, FastH3, and other open-weight video models when their quality and capabilities fit the workload. FastVideo is an independent Apache-2.0 open-source framework; individual model weights and derivative checkpoints remain governed by their own licenses and authorizations.

Every commercial project requires a written rights matrix covering the selected weights, derivative work, deployment territory, reference assets, customer data, and intended use. If a model is not authorized for the required deployment, we qualify another appropriately licensed model rather than treating open weights as unrestricted rights.
