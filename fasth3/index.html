Why FastH3

From a research checkpoint to a usable production system

Base video models are rarely production systems by themselves. Teams still need a repeatable inference graph, hardware-specific kernels, memory planning, request orchestration, output encoding, quality gates, and a way to measure the cost of an accepted clip rather than the cost of a single attempt.

FastH3 reduces the denoising path from the original H3 schedule to four transformer calls. The recommended Preview v1 profile also applies Video Sparse Attention to eligible video-to-video attention tiles. That creates a much stronger starting point for high-volume workflows, but real deployment still depends on output quality, retries, VAE and media-processing time, topology, and target hardware.

Public evidence

What the FastH3 release proves

  • FastH3 Preview v1 is an open-weight four-step T2VA release built on MiniMax H3.
  • The published 15-second, 768p result is faster than playback on eight NVIDIA B200 GPUs.
  • The release supports variable duration, resolution, and aspect ratio in one checkpoint.
  • FastVideo subsequently published local paths for NVIDIA DGX Spark and Apple Silicon.

Licensing

Open framework and open weights are not the same license

FastVideo is Apache-2.0 open source. MiniMax H3 and FastH3 model weights and derivatives are governed by the MiniMax H3 Community License. That license currently excludes the United States, European Union, United Kingdom, and Republic of Korea from its default applicable territory and directs interested deployers in excluded territories to seek authorization from MiniMax.

Nuva Lab scopes any H3 or FastH3 commercial deployment subject to written model authorization, territory, customer use case, and applicable compliance requirements. We can also evaluate model-portable private systems using other appropriately licensed open-weight video models.

FastH3 FAQ

Questions teams ask before deployment

What is FastH3?

FastH3 is FastVideo's few-step, sparse-distilled derivative of MiniMax H3 for synchronized video-and-audio generation. The recommended Preview v1 profile uses four transformer calls and Video Sparse Attention.

Can FastH3 run locally?

Yes. FastVideo has published FastH3 paths for NVIDIA DGX Spark and Apple Silicon, in addition to data-center NVIDIA GPUs. Local does not necessarily mean real-time; latency and memory strategy vary materially by hardware.

Is FastH3 open source?

The FastVideo framework is Apache-2.0 open source. FastH3 uses MiniMax H3 weights and derivatives under the MiniMax H3 Community License, so “open weight” is the accurate model description.

Can Nuva Lab provide a FastH3 API endpoint?

We can evaluate dedicated endpoint and private deployment projects subject to model authorization, territory, workload volume, target quality, and hardware requirements.
